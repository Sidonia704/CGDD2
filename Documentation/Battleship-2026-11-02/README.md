# 3500 cost 战舰框架

本轮将3500预算的参照物改为大型综合战舰。Cube/Wedge/Slab/Pyramid/Block5/6/7/8八类普通船体免费；装甲和功能模块收费。免费船体仍承担真实质量、占格、连接、血量和转动惯量，装甲以费用换取更好的单位质量耐久。标准任务预算3500，靶场不限预算。

## 推进与控制

存活部件变化时缓存总质量、重心、占格分布对应的对角转动惯量、有效喷口及力臂。平移能力来自对应方向推力/质量；转向能力来自该轴力矩/惯量。使用对角惯量近似，不是完整六自由度刚体求解器。

每个推进器的喷口共享单个额定输出，独立的专用推进器独立分配；请求包含平移、自动制动、姿态启动与制动。固定步只遍历缓存喷口，重复使用模块负载对象。先匹配原始能力归一化，再对实际分配施加平滑加速度上限，避免高推力小船小信号过驱。损伤后无反推/反向力矩的方向保留惯性，不能借用不存在的推进器刹停；这会使旧的单向推进蓝图明显更难控制。

Shift继续消耗共享电力、使加速度和转向能力最多乘1.5；总速度上限仍为250m/s。常规推力不扣电。喷口拖尾和引擎音读取实际分配。鼠标偏移仍是持续虚拟摇杆输入，松开鼠标不会自动归中。

摄像机按Rigidbody渲染插值姿态跟随，实际朝向准星使用同一渲染姿态，LateUpdate明确相机先、准星后。相机位置保留船体下半屏构图和缩放，避免重复旋转平滑造成准星与船体显示不同步。战斗弹道仍使用物理姿态。

装配信息框新增模块/机动切页：六向加速度、六向满速刹停距离、三轴转向和转弯半径。按装配变更、数据库与飞控修订缓存，切语言不重新遍历整船。中英文速度行只显示统一限速与加力倍率。

## 数据、验证和回退

权威参数仍在ModuleDatabase、各ModuleDefinition/WeaponDefinition、FlightTuning和BattleTuning。菜单Starframe/战舰框架可打开参数、导入三舰、分项恢复本轮之前的数值。before.json是真实调整前的58个原生资产完整记录（9348个标量、Editor序列化内容、磁盘原文及SHA256）；没有沿用上一轮重建基线。after.json与parameters.csv用于对照。恢复菜单只写白名单数值，可Undo；不回退算法源码，也不覆盖美术/占格/引用/玩家存档。

本轮保留上一轮4.2耐久候选与武器DPS，没有为固定模型的时长直接缩放伤害。27组600米固定目标射击模型全部完成：173.36–319.74秒，中位197.42秒。模型采用实际武器、弹道、盾、供电、损伤及恢复，2秒射击/2秒停火，固定种子瞄准噪声；未模拟双方实际飞行、规避、反击、地形和主动反制，整船瞬时瞄准。它是攻防数值参照，不能证明真人对局时长，也没有进行真人10分钟拼装计时。Matrix目录保存全记录。

调试工具在tools/Battleship20261102；原生资产通过Unity API更新。旧的组件导入/历史调参工具可能覆盖当前参数，更新美术时需保留平衡字段。旧Balance-2026-11-02目录是历史记录，不是本轮权威参数。

15分钟/5波次关卡保持下一阶段范围。

最终验证：483/483 EditMode（54.98秒）；PlayMode包含真实314/545件舰与高推力小型舰闭环3/3、实际靶场精细瞄准1/1、双语机动界面1/1、原页面流程11/11，共16项。默认试飞样例改为四个非共线T6，原小输入与松键收敛断言不放宽。失败中间记录保留，*-final.json是最终通过记录。

实际独立Play复核中英文机动页，Console为0错误/0警告；assembly-en.png、assembly-zh-Hans.png与Interface/保存截图。已原生导入三艘新参考舰，恢复Hangar与真实存储根，workspace-final.json核对原工作船和备份SHA256均未变。未重新构建独立Player。
