# 稳定六轴飞控修复

上一版运行时将各喷口的真实线性力与偏置力矩直接叠加，按点积选择喷口的启发式分配无法保证六个运动通道独立，因而前推、自动制动和转向会互相串扰，出现持续滚转。上一轮短时/收敛测试不足以证明单向直飞正确。

本轮采用用户允许的简化方案：稳定的街机六轴性能模型，不声称求解真实物理配平。布局、喷口朝向、质量和惯量继续影响各方向能力，运行时只应用被请求的平移/旋转轴。平移不附带偏置扭矩，转向不附带平移或其他轴扭矩。每个旋转轴以较弱方向的能力作为两个方向共同的上限，保证正转、反转和制动能力的数值对称。

每个模块缓存各通道的最佳喷口与贡献；同一模块多通道请求按一个额定输出预算分摊，独立模块不互相抢预算。尾焰与音效仍读取分配后的喷口油门。单通道满输入与装配显示的能力一致；组合输入会共享模块输出。没有新增能量、费用、模型或存档变动。缺少某一方向的推进器仍无法凭空获得该方向推力；完全失去某轴控制能力时仍可能保留已有惯性。

验证：486/486 EditMode通过；新增4项实际PlayMode分别使用当前玩家Balance-Heavy（172件）及Battleship-Heavy/Maneuver/Assault（545/314/504件），逐轴测试六向平移与制动、三轴转向与松键停转，并在删除一个推进器后检查加力前进不会自转。原精细瞄准检查1/1通过，原阈值未放宽。当前玩家配装仅只读载入，测试核对存档原文未改。未重新打包Player。

545件、81喷口的10000次热身后缓存分配测量：约0.008236ms/次、零托管分配，仅该计算部分，不是整帧基准。生产控制器现每步一次分配；旧版需要的偏置力矩补偿预分配已删除。

核心改动：FlightTuning.cs中的ShipPerformance/AllocateWrench，ShipFlightController.cs。本目录保留这两份源码的调整前副本（*.before.cs.txt）；原生参数资产、蓝图和美术未改。
