# 视觉精修：均匀磨砂玻璃

统一使用石墨烟灰、银白文字和少量冰青强调色。面板没有人为上下渐变、顶部亮带或外描边；磨砂感来自背景模糊、受控透色和极轻颗粒。船体材质与功能参数保持原样。

## 可直接调整

| 项目 | 位置 |
|---|---|
| 全局玻璃、按钮和文字颜色 | `Assets/_Starframe/Resources/UI/WorkbenchTheme.asset` |
| 玻璃模糊半径、透光亮度、透过背景的饱和度 | 同一资产的「磨砂玻璃」部分 |
| 单独关闭本轮磨砂光学与按钮风格 | 关闭 `Frosted Finish`，重新进入页面 |
| 星空强度、星点、尘带色彩 | `Assets/_Starframe/Art/Materials/Environment/SpaceNebula.mat` |
| Bloom 阈值、散射和统一色彩 | `Assets/_Starframe/Settings/Rendering/ConstructionPostFX.asset`、`SpaceTestRangePostFX.asset` |
| 两张关卡预览 | `Assets/_Starframe/Art/UI/Operations/`；通过 MissionDefinition 的 Thumbnail 替换 |

本轮星空仍使用现有的程序化球形背景，无需外部 HDRI。`Quiet Sky = 0`、Exposure = 1、Nebula Strength = 1.2、Star Strength = 3.2 可单独恢复之前的星空表现。

## 分项回退

`Before/` 已逐文件保存修改前版本，并保留原路径。配色、天空、菜单排版、战斗指示器和网格分别留有副本，可以只撤回其中一项。游戏蓝图、部件数据、武器组和战斗算法没有加入这些视觉备份。

| 想撤回的部分 | 对应原文件 |
|---|---|
| 玻璃和控件 | UiTheme、GlassUiPalette、UIBackdropBlur、MenuSurface、ShipEditorUI、RangeHUD |
| 星空 | SpaceSky.shader、SpaceNebula.mat |
| 首页与内页排版 | App 下的 GameAppBootstrap、GameAppScreens、SettingsScreen、WeaponGroupScreen、GameResultsScreen |
| 战斗图形 | TargetAimGraphic、SphereRadarGraphic、ShipStatusGraphic |
| 网格 | ConstructionGrid.shader、FlightRangeGrid.shader |

装配组件库现在首次进入时从顶部显示，避免第一行标题和图标被裁切。损伤继续使用红色，锁定和警告使用琥珀色。

## 验证

212 项 EditMode 与 21 项 PlayMode 回归通过。Windows 版本重新打包语言资源后，两次独立启动均通过 53 项流程检查，运行错误为 0；最终记录见 `PlayerValidation.json`，截图见 `Previews/`。打包仅保留原有 Pipeline 未配置运行时服务的提示，不影响游戏运行。
