## 修正的代码问题

1. **旧模板代际断裂失败。** 活体持有旧几何，源资产被改小/更新后再打断，碎块原来会用当前源代际检查，拒绝仍有效的旧模板。现沿用捐出物体持有的模板租约；染色碎块保留其材质代际并独立持有运行时材质，捐出物体销毁不会损坏碎块。
2. **预览构造失败泄漏。** 预览未加入窗口管理列表前发生异常，原来可能泄漏部分网格/子物体或共享引用。现事务式获取、提交和回滚，失败仅释放自己的租约。
3. **旧升级菜单部分写入。** `VisualPowerUpgrade` 仍依赖已不存在的旧素材名。现先检查所有输入，缺失即在任何资源写入前停止；移除这个美术升级器对飞行/武器/电力平衡值的历史硬重置。未执行升级，也未改当前参数资产。
4. **缺少初始断连提示。** 工作室增加按资产修订缓存的连通性提示，避免每次绘制都遍历；数据仍可编辑，未自动改地图结构。
