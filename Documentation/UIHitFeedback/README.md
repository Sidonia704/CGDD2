# 命中反馈

玩家弹丸对船体、护盾、残骸实际造成伤害后触发。同一弹丸穿透多个部件只确认一次；场景碰撞、未造成伤害和敌方命中不触发玩家准星。密集命中最多每秒反馈 8 次，超出的合并丢弃，不积压延迟动画。

动画为珊瑚红斜线从短到长，同时提亮、淡出；十字间距从 11 像素收缩至 3 像素，再恢复。默认时长 0.24 秒，准星位置、虚拟摇杆和弹道计算不变。

Unity 菜单 **Starframe → UI 设计 → 打开设计配置**，Inspector 中的 **武器命中反馈** 分组可实时调整开关、最大频率、时长、十字间距、臂长、命中线长和颜色。关闭“启用命中反馈”即可恢复本轮之前的准星绘制。源码备份在本目录 `Before/`。
