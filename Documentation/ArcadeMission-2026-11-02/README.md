# 土星环清剿 / Saturn Ring Sweep

正式关卡入口：主界面唯一关卡卡片 → 选择出击船 → 确认10000 cost预算 → 出击。原靶场仍用于自由训练。

五波累计50小型、15大型、2主力舰，共67艘；按批次到达，最多12艘同时存活、3艘大型和1艘主力舰。同时主要攻击玩家的单位默认3艘。玩家核心被毁则失败，清除第五波所有作战单位则胜利；残骸不计敌人。波间20秒，释放鼠标，可点击按钮或按Enter提前开始下一波。15分钟是待玩家试玩校准的目标，不是强制倒计时。

## 试玩与编辑敌舰

蓝图管理 → 导入敌舰模板，会复制七种敌舰和旗舰备用配装共八份到蓝图库。同名自动编号，不改变当前装配、不覆盖已有蓝图。选中副本后载入装配即可改船。改好的玩家副本不会自动覆盖关卡模板；要替换关卡敌舰，在Unity对应EnemyArchetypeDefinition的blueprint引用中指定新导出的JSON。

## 调整入口

- `Assets/_Starframe/Settings/Game/SaturnRingWaves.asset`：五波批次、数量、入场延迟、并发上限、间歇、积分连击窗口。
- `Assets/_Starframe/Data/Enemies/*.asset`：敌舰蓝图、备用配装、积分和行为配置。
- 同目录行为配置：偏好射程、巡航/交战速度、掠袭或稳态交战、反应、射击间隙、瞄准误差、航向平滑与地形探测。
- `Assets/_Starframe/Settings/Game/ice.asset`：出击预算10000及场景SaturnRing。
- `Assets/_Starframe/Scenes/Gameplay/SaturnRing.unity`：独立正式关卡，沿用矿区地图和土星环境。直接在Editor播放时使用内置主力舰预览，不改玩家工作区。

## 实现边界

AI通过普通飞控输入驾驶，组件性能、有限供能、武器充能/锁定、6秒脱战恢复、核心死亡和永久可破坏残骸都使用共享战斗系统。战术方向与速度连续过渡；普通训练保留已有模式，关卡按舰型配置行为并轮换攻击机会。地图探测使用错帧NonAlloc查询。

普通不透明残骸以256实例为一批绘制，发光/透明/带独立属性的显示继续使用源Renderer。碰撞、HP、独立岛漂移均保留；拓扑改变会使批次更新。此优化没有把完好的残骸自动删除。

## 工具与基线

`tools/ArcadeMission20261102/`保存生成/安装器与原生验证工具。原生资产必须通过Unity API修改。BuildEnemyFleet会重建模板及默认AI配置，因此开始手动平衡后不要不加选择地重新运行它。

`before/`保存本轮已有文件的修改前副本；`Fleet/summary.json`记录生成的实际舰船参数。各模块数据可独立调整。源文件存在接口依赖，回退源码时需要连同对应接入一起检查编译，不能把单个旧文件直接覆盖到新接口上。

最终验证结果见同目录JSON和native-mission.txt。原生整场探针的自动核心伤害用于验证67舰计数、残骸和结算，不代表普通玩家命中率或15分钟通关。Editor观测也不等同独立Player性能保证。
