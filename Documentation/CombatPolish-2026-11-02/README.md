## 敌机设计建议（设计目标，未生成新蓝图）

10000 是玩家出击上限，普通敌人无需各自达到上限。建议 5 波逐步组合下列角色：

| 角色 | cost 目标 | 设计要点 |
| --- | ---: | --- |
| 轻型截击机 | 1200–1800 | 1–2 门轻武器；侧向/转向强；薄装甲；适合作为早期练习目标。 |
| 突击艇 | 2400–3500 | 2–4 门机炮/激光；前冲强，侧移弱；短时正面威胁后露出侧翼。 |
| 导弹支援舰 | 3500–5000 | 2–3 发射器、少量近防；远程压制但低滚转，迫使玩家使用地形与干扰弹。 |
| 重型近战舰 | 5500–7500 | 高装甲/护盾、短程火力；速度慢；后方推进器/电源留明显弱点。 |
| 指挥战舰 | 8500–10000 | 3–4 组不同射程武器，分层火力与供电；避免全向无死角。 |

优先用组合、方位和开火窗口形成难度；大船供电峰值不宜长期超过输出，短时超载则由储能承担。
