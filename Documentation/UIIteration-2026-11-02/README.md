# UI 与交互迭代 · 2026-11-02

本轮按已批准的 framework 实施。首页按追加要求只显示**一个关卡卡片**；另一个关卡定义保留在目录中。关卡真实内容仍显示开发中，出击整备、资源核对与返回装配的流程可用。

## 已实施

- 公共视觉：中性深色、均匀透光磨砂玻璃；没有新增面板渐变、蓝色外框或黑色描边。亮背景经过均匀亮度压缩，文字与图标独立保持清晰。
- 首页与部署：当前舰船作为上方主视觉，单个宽幅任务卡在下方；预算、开发状态、问题列表、修改舰船与出击确认分层显示。
- 装配：真实组件搜索、可滚动组件库和信息区；明确的放置/删除/聚焦按钮；成本、质量、耐久和供能摘要；放置失败原因提前显示；保存预填名称，载入替换草稿需要确认。
- 武器组：1–4 组自适应卡片，5–8 组排列两行；区分数字键启用/停用与开火键；列表显示武器类型，只强调当前武器或分组的连线；预览舰船自动适配展示空间。
- HUD：精简常驻遥测，F1 展开诊断；左下自舰状态、护盾和能量，右下锁定目标，右上雷达，底部武器组；导弹、干扰弹和警告单独分区。敌方红色、地图命中低调白色继续保留。
- 设置：增加真实可用的文字大小、玻璃模糊、HUD 动画强度控制。字号放大时对长文本进行有界适配，不改变字形宽度。玻璃模糊关闭不会模糊游戏视野。
- 交互：输入文本时阻止冲突的飞行/建造快捷键；新增悬停帮助；弹窗隔离键盘导航和焦点，关闭后恢复；菜单的固定 1920×1080 设计平面在宽屏和 4:3 下等比适配。HUD 资源条使用轨道内比例填充。
- 本地化：新增 15 个中英文表项；检查中文、英文及较大字号。玩家舰名仍使用中文字体回退，英文不压缩字宽。
- 追加要求：蓝图库成为独立页面，提供列表/搜索、真实舰船预览、明确载入、命名保存/覆盖及确认删除。首页和装配可进入，选择预览不改变当前工作舰船。靶机选择、数量与行为模式集中在靶场设置；装配和蓝图库不显示靶机控件。

## 调整入口

- Unity 菜单 **Starframe → UI 设计 → 打开设计配置**：`Assets/_Starframe/Resources/UI/WorkbenchTheme.asset`，控制公共颜色、磨砂和准星反馈。
- 游戏设置 → 辅助功能：文字大小 85–125%、玻璃模糊、HUD 动画强度；采用已有的暂存/应用/撤销流程。
- `Presentation/UiStyle.cs`：公共字号、控件状态和菜单安全设计平面。
- `App/MenuSurface.cs`：公共控件、玻璃采样、工具提示。
- `Presentation/UiModalScope.cs`：弹窗键盘导航隔离。

## 单独撤回

`before/frontend/`、`before/assembly/`、`before/combat/` 和 `before/shared/` 保存了本轮操作前的准确源文件。`theme-before.json` 是修改前的原生主题值；`source-manifest.json` 记录源文件、备份及前后 SHA256。

使用 Pipeline `run_script` 执行 `tools/UIIteration20261102/Restore.cs`，入口 `UIIterationRestore.Main`。参数为 `["frontend",false]`、`["assembly",false]`、`["combat",false]` 或 `["glass",false]` 时**仅预览**；第二个参数为 `true` 才应用。必须先退出 Play。

- `frontend`：首页、部署、设置、结果和首页舰船预览。
- `assembly`：装配 UI、装配导航、武器组和连线。
- `combat`：战斗 HUD、雷达/目标图形、加载页和靶场菜单。
- `glass`：公共配色/玻璃 shader 和原生主题值；保留新的交互辅助代码与设置字段。

恢复工具在发现后续源码修改时会拒绝覆盖，避免误删下一轮成果。它不碰蓝图、存档、战斗参数、地图和模型。新增测试、公共辅助脚本和导航枚举/返回字段保留，不需要为了回退某个页面一并删除。前端和装配涉及新增蓝图库的入口依赖，撤回页面流程时应一起核对链接；纯玻璃/配色和战斗外观可独立撤回。原有“恢复本轮之前的全部设计”菜单来自更早的迭代，只切换旧主题开关，不能代替这里的源码分组回退。
