# Starframe UI 刷新规范与回退

## 视觉与布局

采用克制的磨砂玻璃、直角边缘和透明模块图标。装配页以 1920×1080 为参考：外边距 32 px、常用间距 16 px。左上是 520×88 的编辑器标题与蓝图身份；右侧为 384×680 的可滚动模块库、下方 384×240 的模块信息卡，底部放置保存与载入操作。工作区左下安排测试飞行、状态和旋转读数，操作提示沿底边排列。模块按类别分组；图标保留 48/96/144 px 的实际横向占位，名称以 12 px 小字显示，选中状态用选中图标和短强调线表示。

文字层级以清楚、紧凑为准：页名约 23 px，模块名与分区标题 16–17 px，状态、按钮和模块数据 13–15 px，辅助提示与类别计数 12–13 px。基础文字使用浅色，次要信息使用低对比灰青色；冰川青用于主要操作和选中状态，琥珀色提示需留意的操作，珊瑚红表示危险或错误。

磨砂面板由 `UI/BackdropBlur` 材质绘制。`WorkbenchTheme` 提供玻璃底色、模糊半径、颗粒和高光强度；按钮、文字和语义强调色集中在同一主题资产中。后续首页、设置页与其他内页应读取 `UiTheme.Current` 并复用 `GlassUiPalette` 的颜色和玻璃应用方法；各页面保留自己的布局，不复制一套颜色常量。

## 主题资产与回退

主题资产位于 `Assets/_Starframe/Resources/UI/WorkbenchTheme.asset`，运行时通过 `Resources/UI/WorkbenchTheme` 读取。Inspector 中六个开关可独立控制：

- `refinedGlass`：统一玻璃材质与配色。
- `assemblyLayout`：装配页布局和内容。
- `flightLayout`：飞行 HUD 布局和内容。
- `aimReticle`：准星、预瞄和目标指示器。
- `tacticalRadar`：平面战术雷达。
- `statusSchematic`：船体状态图。

修改布局开关后，退出并重新进入对应页面以应用布局。需要单独回退时，只关闭对应开关；需要整体回退时使用 Unity 菜单 **Starframe/UI 设计 → 恢复本轮之前的全部设计**。菜单 **打开设计配置** 会选中主题资产，**启用本轮全部设计** 会重新启用六项。也可通过 `Create > Starframe > UI > Design Theme` 创建主题资源。

刷新前源码备份位于 `Documentation/UIRefresh-2026-10-18/Before/Assets/`，其中保留被替换的原始脚本和着色器，可用于手动恢复具体文件。主题开关只控制 UI 外观和布局，不改动游戏参数或蓝图数据。建议先用开关回退，再决定是否恢复源码；不要在 Unity 运行时复制脚本，以免触发运行中的域重载。

## 飞行界面与实机预览

速度是首要读数，详细性能参数按 F1 展开。左下自身状态与右下目标状态采用相同尺寸；核心高亮、受损部件红色、脱落部件不再显示，目标姿态保持相对朝向。雷达保留三环平面投影与高度连线，锁定接触点使用琥珀色。准星采用开放体素笔画，中心静止时隐藏重叠的游标角标。预瞄及偏移输入的计算沿用原有逻辑。

弹窗使用独立 `dialogTint`，底色更深，防止亮色船体影响文字阅读；普通面板保留通透感。新增页面应复用同一主题：主要操作用实色强调按钮，次要操作用低透明底，删除等操作平时使用琥珀色文字，仅确认时使用强调底色。不要为面板增加蓝色或黑色轮廓。
