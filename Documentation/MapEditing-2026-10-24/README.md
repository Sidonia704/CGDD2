# 地图编辑长按与大资产收尾

范围仅地图工作室；未继续 AI、飞行或全游戏测试。用户确认法向正常，本轮不再修改模型法向或绕序。

- 单击立即操作一次；长按默认等待 **0.65 秒**，之后每 **0.18 秒**最多操作一次。右侧笔刷区可调整这两个值。
- 松开、失焦、切换工具/资产、进入视角操作均结束笔画。卡顿后不补发连续操作，同一笔画可整体撤销。
- 有船体模型且达到 512 格时，编辑预览使用 Unity 原生 `Mesh.CombineMeshes`，避免逐顶点 C# 复制和预览用碰撞构建。模型、原始法向、材质、接缝保留。
- 地图中重复的完整资产共享预览网格；受损副本独立生成网格，最后一个使用者释放资源。静止视角复用已渲染的预览纹理。
- 这不是每格一个 Prefab，也不是运行时区块系统。实际地图的漂浮、受击和断裂规则未改。

同一 Editor、临时内存数据，添加一格后的同步预览重建：

| 原有格数 | 修改前 | 修改后 |
|---|---:|---:|
| 1,000 | 69.7 ms | 27.8 ms |
| 4,096 | 362.3 ms | 50.6 ms |
| 10,000 | 757.3 ms | 124.1 ms |

这反映 CPU 重建响应，不包含完整交互帧的 GPU 渲染成本，也不是 FPS 保证。一万格仍有短暂停顿；更大规模仍需降低模型顶点量或另做增量网格更新。

证据：`Before.json`、`After.json`、`Checks.json`；`NativePreview.png` 为实际隔离预览。临时验证覆盖长按、重复节奏、失焦、共享网格、损伤隔离、资源释放和源资产不变。未修改用户蓝图/地图内容。测试脚本在 `Temp/MapEditBenchmark.cs`、`Temp/MapEditVerify.cs`。

最终无 C# 编译失败。Console 保留 CLI 新命令名 `script eval` 对旧 Pipeline 的自动回退记录（`No command named 'script'`），后续 eval 实际成功；这不属于地图运行错误，未清空 Console 掩盖记录。
