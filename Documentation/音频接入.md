# 音频配置

在 Project 中选中 `Assets/_Starframe/Resources/Audio/GameAudioTuning.asset` 即可调整声音，无须改代码。

- `Cues`：每项的 Clip、Gain、Pitch、Pitch Variation、Minimum Interval、Priority（数值越小越优先），以及 Interface / Effects 音量通道。清空 Clip 或将 Gain 设为 0 可单独关闭。
- `Own ship propulsion`：推进循环音量、普通/加速音调、推力渐入渐出；`Boost Volume Multiplier` 默认 1.75，控制加力音量。声音由仍可工作的推进器实际油门驱动，不按推进器数量叠加。
- `Music`：首页/装配背景与靶场分别设置。靶场音乐暂留空，让射击和定位提示更清晰；切换采用淡入淡出。
- `Voice limits and distance`：并发声部上限、外部声效距离、边界提示间隔、低血量提示阈值及间隔。

游戏设置中的主音量、音乐、音效、界面音量及失焦静音继续生效。设置预览不写入偏好；取消后恢复原值。打开靶场菜单会降低战斗声并淡出推进循环，退出场景会释放战斗事件订阅和声部。

接入了 UI 点击、蓝图保存/载入与确认提示、放置/删除/旋转/无效放置/核心启动、激光发射、锁定与解除、推进与加速、边界警报、自身核心爆炸、玩家重生。命中音效已关闭；敌船被击毁不播放爆炸声，锁定的敌船被击毁时仅播放一次脱离锁定提示，未锁定的敌船被击毁不额外提示。导入整张蓝图、缩略图和部件恢复不会逐块播放装配声。多炮同帧有独立限频；自身爆炸和锁定提示优先于普通声效。

原素材保留在 `Assets/_Starframe/assetsForCodex/Starframe_Audio_Starter_Pack`，处理后的 19 个文件在 `Assets/_Starframe/Audio/Clips`。处理包括去直流、柔化高频、短淡入淡出、峰值留余量、背景音裁去末尾约 6 秒静音、循环交叉接缝。暂未使用 Flight_Combat_Loop、High_Speed_Hull_Whine、Critical_Damage_Pulse，减少重复背景、持续啸叫及反复警报。这轮工具无法直接听音，筛选依据为波形、频谱及技术检查，主观听感仍需在游戏中确认。

新增的 `assetsForCodex/lazer.mp3` 约 11.57 秒，前后静音、中间为约 7.3 Hz 连续脉冲。现用发射声是其中 2.478–2.609 秒的单发（0.131 秒），去低频、柔化高频、短淡出并匹配响度，另存为 `Laser_Shot_New.wav`。旧版 `Laser_Shot.wav` 保留备用；在配置的 LaserShot 项切换 Clip 即可撤回这一次替换。

放置和删除已改为自行合成的短促机械触点声：`Block_Place_Click.wav`（轻脆）和 `Block_Remove_Click.wav`（稍低沉），均为 78 毫秒。采用快速衰减的振动频率叠加，不含噪声层、混响或沙沙尾音。PlaceHull / PlaceModule 共用新的放置音，RemovePart 使用删除音。原 Part_Place_Soft / Part_Place_Metal / Part_Remove 仍保留备用。生成脚本暂存 `Temp/generate_block_clicks.py`；调节音量和音调直接使用配置资产即可。

引擎现用用户提供的 `assetsForCodex/engine.mp3`，保留音色，转换为单声道并交叉处理循环接缝、匹配音量，另存为 `Engine_User_Loop.wav`。普通喷射音量随有效推力增大，加力默认再提高至 1.75 倍并平滑改变音调。原 Maneuver_Jet 的气流提示默认关闭（Gain=0）。之前合成的 `Engine_Low_Rumble.wav` 与旧 `Thruster_Loop.wav` 保留备用。

需要重建缺失的配置时，使用菜单 `Starframe > Audio > Import prepared audio and create tuning`；已有配置不会被重置。重新处理音频不应覆盖原始文件。
