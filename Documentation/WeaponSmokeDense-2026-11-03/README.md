# 双方交火烟带增强（2026-11-03）

本版取代上一轮克制烟尘默认值。用户明确要求己方／敌方导弹、炮火在视窗中交错拉烟，并进一步要求实弹弹道烟也明显。

## 当前表现与参数

- 实弹：保留5米短枪口烟，同时沿真实扫掠弹道采样淡白烟线；拉长billboard形成连续的细烟段，寿命4.5秒，基础直径1.5米、峰值alpha0.32。
- 导弹：沿真实点火后轨迹留下更宽的烟带，寿命6秒，基础直径3米、峰值alpha0.36、采样间距3.2米。
- 枪口烟：寿命6.5秒，基础直径2.1米、峰值alpha0.30；随烟龄扩散，留在世界发射地点。
- 粒子视窗最小尺寸0.0012，改善远处炮火烟线的可读性；世界采样点仍来自真实发射／扫掠位置。
- PS共6个：己方与敌方各有导弹／实弹路径／枪口三类固定池。总容量导弹8192、实弹路径8192、枪口4096，双方各占一半。
- 每帧发射总预算384；双方每侧分别保留枪口32、导弹64、弹道96的预算，高射速实弹不会抢空导弹或对方的配额。5500米外拒绝发射。
- 所有新参数由WeaponSmokePool脚本字段默认值决定；未改变武器资产数值、弹速、伤害、射速、制导、胜负或输入。激光／光束不冒烟。

Shader调整了柔边密度，烟本身不发光。采样中心只在已解析扫掠段内；粒子宽度／自然扩散及短枪口烟会有可见体积，靠深度测试／软交接遮挡。弹丸回收后仍按烟龄消散。
